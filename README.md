# Heera Luxe website

New website for Heera Luxe, luxury women's heels and bags. It will replace [theheera.in](https://www.theheera.in).

Built with Next.js 16, Tailwind CSS 4, shadcn/ui, Axios, Zod and react-hook-form.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing by chat

Open the Claude app, go to the **Code** tab, pick this repo, and describe the change. Project rules for Claude are in `CLAUDE.md`.
